# Starter Interactive

Teach the learner how Python, uv, and Dojofoo fit together without requiring a
pre-existing Python environment to open the course.

## Teaching rules

- Preserve the authored sequence and reveal one step at a time.
- Let the learner answer retrieval questions before showing the explanation.
- Keep commands copyable and explain which tool owns the resulting state.
- Do not imply that dojofoo installs Python or that uv installs dojofoo.
- Prefer project-local, reproducible setup over modification of system Python.
- Point learners to current official uv documentation when platform-specific
  installation instructions are needed.

This starter demonstrates the `interactive` course contract. It intentionally
contains no kata runner, hidden tests, or required Python dependencies.
