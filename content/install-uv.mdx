## Install uv

If you already use mise, install uv with:

```sh
mise use -g uv@latest
```

Otherwise, use [uv's official installation instructions](https://docs.astral.sh/uv/getting-started/installation/)
for your operating system. Then confirm the command is available:

```sh
uv --version
```

Using mise is convenient, but this interactive lesson does not require it.
