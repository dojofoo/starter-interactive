## Initialize dojofoo

In the same project directory, initialize dojofoo for your coding harness:

```sh
npx dojofoo install --codex
```

Replace `--codex` with another supported harness flag when appropriate. Then
install this course and open the local UI:

```sh
npx dojofoo add dojofoo/starter-interactive
npx dojofoo ui --open
```

The Python environment and dojofoo learning state now coexist while remaining
independently replaceable.
