## You now have a reproducible baseline

The resulting workspace has three clear layers:

- **mise** can pin and install cross-language tools.
- **uv** manages Python and its project dependencies.
- **dojofoo** keeps course/session state and presents the lesson.

Use this repository as the baseline for another interactive dojo: edit the
documented `dojo.yaml`, replace the MDX content, and keep downloadable assets
limited to material the learner actually needs.
